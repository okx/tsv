## 升级原因与变化

本次主要发布审计整改过程中已采纳且尚未进入上一生产版本的修复，另包含 LP NFT 许可证依赖调整。

- **资产准入校验：**注册资产、更换 LegalShareAdapter 时，要求倍率接口可用且倍率非零；不会自动重新检查或迁移已有资产配置。
- **SBT 权限约束：**后续身份配置仅接受 Swap、LP 及其组合，拒绝额外权限位；不会自动改写既有身份记录。
- **存量池交易修复：**禁止 QuoteToken 新池准入后，已有池经授权 Adapter 的卖出不再被额外的准入标志阻断。池状态、身份、Adapter、接收方及交易限制继续生效。
- **内存管理修复：**校验库为静态 getter 调用参数分配独立缓冲区，避免后续分配复用未登记的临时内存。
- **LP NFT 基类调整：**以适配后的 OpenZeppelin ERC721 替换原 Solmate 基类，保持存储兼容、Permit 签名域和禁止转让的限制。该项不代表替换了所有第三方依赖或作出完整许可证合规结论。

已经包含在上一生产基线中的历史审计修复不重复列为本次新增变化。源码中的 LegalShareAdapter 构造检查仅适用于新实例，本次未重建既有 LegalShareAdapter。
