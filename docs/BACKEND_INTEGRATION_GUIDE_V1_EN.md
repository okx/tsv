# TSV backend integration guide (English)

The canonical bilingual [backend integration guide](./BACKEND_INTEGRATION_GUIDE_V1.md) includes the English reference after the Chinese section. Use its current interfaces together with the [generated ABI](./artifacts/README.md), [external adapter boundary](./EXTERNAL_DEX_ROUTER_ADAPTER_TSV_INTEGRATION.md), and the [public deployment address inventory](../deployment/README.md).

External implementations are not required to compile this repository. Resolve deployed SBT, checker and adapter addresses from a reviewed deployment configuration; verify their ABI and on-chain bindings before use.
